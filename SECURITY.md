# Seguridad

Fusion ejecuta trabajos en equipos remotos y debe tratar esa ejecución como
ejecución remota de código controlada.

## Reportar una vulnerabilidad

No abras un issue público para vulnerabilidades. Reporta el problema de forma
privada enviando un correo al responsable del proyecto en el repositorio.

Incluye:

- Descripción del problema y posible impacto.
- Pasos para reproducirlo.
- Versión o commit afectado.
- Configuración y plataforma utilizadas.
- Prueba o registro que ayude a confirmar el fallo.

Tras recibir el reporte, se confirmará la recepción y se acordará una solución
coordinada antes de publicar detalles.
